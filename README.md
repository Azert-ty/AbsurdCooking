# AbsurdCooking

## Personal Game Development Project

AbsurdCooking is an early game development project created to explore gameplay programming and interactive systems in Unity.

The project served as a practical experimentation ground for developing and testing different gameplay mechanics while improving my understanding of Unity and C#.

## Features Explored

- Player movement
- Gameplay interactions
- Physics-based systems
- Projectile systems
- Enemy behaviors
- Finite State Machines
- 2D gameplay systems
- UI and gameplay management

## Technologies

- Unity
- C#
- 2D Game Development
- Gameplay Programming
- Git / GitHub

## Project Status

AbsurdCooking is currently **on hold**.

As the project evolved, I decided to redirect my efforts toward a more structured game development project with a stronger focus on stealth gameplay, enemy AI and level design.

This transition led to the development of **Le Coffret du Délégué**, a 2D top-down stealth game prototype developed as my Bachelor's degree final-year project.

## What I Learned

Working on AbsurdCooking helped me develop a stronger understanding of:

- Unity project organization
- Gameplay programming in C#
- Designing reusable gameplay systems
- Debugging and iteration
- Building and testing interactive mechanics

The project remains an important step in my progression toward game development.
